# Yandex Telemost Linux Client

Неофициальный десктопный Electron-клиент **Яндекс Телемост** для Linux (Fedora, Ubuntu, Arch Linux).

---

## ✨ Возможности

* **Демонстрация экрана через PipeWire и WebRTC:**
  Поддержка захвата экрана и окон в окружениях Wayland и X11 (`--enable-features=WebRTCPipeWireCapturer`).
* **Прямой вход по ссылкам из Яндекс Календаря и браузера:**
  * Автоматическая распаковка редирект-ссылок Календаря (`sba.yandex.net/redirect?url=...`).
  * Полная поддержка протоколов `telemost://`, `telemost://ychat/...`, `ychat://` и прямых ссылок `/j/<id>`.
  * Корректная работа как с обычными аккаунтами (`telemost.yandex.ru`), так и с корпоративными **Яндекс 360** (`telemost.360.yandex.ru`).
  * Отключение промежуточных заглушек «Продолжить в браузере / Открыть в приложении» — видеовстреча запускается сразу внутри окна клиента.
* **Сохранение сессии:**
  Автоматическое сохранение авторизационных сессионных cookies между перезапусками.
* **Нативная интеграция с рабочей средой:**
  Поддержка жестов тачпада (`TouchpadOverscrollHistoryNavigation`), системных шрифтов и эмодзи, корректный `StartupWMClass` для панели задач.

---

## 🚀 Установка и запуск

1. Разместите файлы клиента в `/opt/yandex-telemost` (вместе с рантаймом Electron).
2. Установите скрипт запуска и ярлык приложения:
   ```bash
   sudo cp yandex-telemost.sh /usr/local/bin/yandex-telemost
   sudo chmod +x /usr/local/bin/yandex-telemost
   sudo cp yandex-telemost.desktop /usr/share/applications/
   sudo update-desktop-database
   ```
